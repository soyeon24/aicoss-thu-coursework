# AICOSS × THU Ulm Summer School 2026 — Coursework

My graded exercise notebooks from the AICOSS–THU global student program
(Technische Hochschule Ulm, July–August 2026): three weeks of data science, classical ML,
deep learning and LLM work, followed by a one-week capstone.

The capstone (1st place, DASU "Long-Context, Beyond RAG" challenge) lives in its own repo:
[soyeon24/shared-pass-qa](https://github.com/soyeon24/shared-pass-qa).
